# The World Today — Thursday 26 November 2026

An entry for the [make.fun bounty "Sum up 26 November's world news in one image"](https://make.fun/bounty/news-image-20261126) ($100 shared by the top 50).

`main.py` (Python 3, standard library + Pillow only, no network) draws a
newspaper front page, 1024×1024, summing up Thursday 26 November 2026:

- **Lead:** leaked Russian statistics analysed by the BBC put Russian war
  dead at **490,334** since the 2022 invasion of Ukraine — a toll the
  Kremlin has never published; Kyiv was hit by ballistic missiles as
  Ukraine says it struck a Russian air base.
- **United States:** a federal judge blocks President Trump's second
  birthright-citizenship order.
- **Thanksgiving:** a coastal storm forces the first-ever weather
  postponement of the 100th Macy's Thanksgiving Day Parade in New York.
- **Also:** Colombia marks ten years since its peace accord; Kenya
  discharges its last Ebola patient as the DR Congo toll passes 5,300;
  briefs from Cairo, Nigeria and North Korea.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024×1024 PNG). Running it twice produces
byte-identical output.
